## ความสามารถ
- **ดูเอกสาร**: เลื่อนต่อเนื่อง ซูม (Ctrl+ลูกกลิ้ง) พอดีกว้าง/พอดีหน้า ภาพย่อ ค้นหา (Ctrl+F) คัดลอกข้อความ เปิดหลายไฟล์เป็นแท็บ ลากไฟล์มาวาง รองรับไฟล์มีรหัสผ่าน
- **รูป / ลายเซ็น / ข้อความ เป็นวัตถุอิสระ**: หลังวางแล้ว **คลิกเลือก → ลากย้าย → ลากมุมย่อขยาย** (รูป: มุม = คงสัดส่วน, กด Shift ที่มุม หรือลากขอบ = ยืดอิสระ • ข้อความ: ลากมุม = ย่อ/ขยายตัวอักษร, ลากขอบซ้าย/ขวา = ปรับความกว้าง) • ลูกศรบนคีย์บอร์ดขยับทีละ 1 pt (Shift = 10 pt) • **Ctrl+C / Ctrl+V** คัดลอก-วาง (ข้ามหน้า/ข้ามไฟล์ได้ วางภาพจากคลิปบอร์ดได้) • **Ctrl+D** ทำสำเนา • **Delete** ลบ • คลิกขวา: นำมาหน้าสุด/ส่งไปหลังสุด • ดับเบิลคลิกข้อความ (หรือ F2) เพื่อแก้ไข • ย้อนกลับ/ทำซ้ำได้ทุกขั้น — ตอนบันทึก/พิมพ์จึงฝังลงเอกสารจริง
- **ข้อความ**: ฟอนต์และขนาดเลือกจาก dropdown (หรือพิมพ์ขนาดเอง) ตัวหนา/เอียง/เส้นใต้ สี ชิดซ้าย-กลาง-ขวา แทรกวันที่ พ.ศ. — สระวรรณยุกต์ไทยถูกต้อง
- **แก้ / ลบ / เพิ่มข้อความบนเอกสารเดิม**: เครื่องมือ “แก้ข้อความ” คลิกที่ย่อหน้า (หรือลากกรอบเลือกบางส่วน) → แก้หรือกด “ลบข้อความนี้” — ข้อความที่แก้กลายเป็นกล่องข้อความ ย้าย/แก้ต่อได้ • เพิ่มข้อความใหม่ด้วย “ใส่ข้อความ”
- **ลายน้ำ**: ข้อความ (เช่น ลับ / ฉบับร่าง) หรือรูป/โลโก้ ปรับความโปร่งแสง มุมเอียง วางกลางหน้าหรือซ้ำเต็มหน้า อยู่หน้า/หลังเนื้อหา เลือกทุกหน้า/บางหน้า มีตัวอย่างก่อนใส่
- **มาร์กอัปอื่นๆ**: ไฮไลต์/ขีดเส้นใต้/ขีดฆ่า, วาดเส้น, ลบ/ปิดทับ, ปิดข้อมูลลับถาวร (Redact)
- **จัดการหน้า**: หมุน ลบ แทรกหน้าว่าง ทำสำเนา เลื่อน/ลากสลับลำดับ แทรกจากไฟล์อื่น แยกหน้าเป็นไฟล์ใหม่ ส่งออกเป็นรูป
- **รวมไฟล์**: PDF + รูปภาพ หลายไฟล์ จัดลำดับ เลือกช่วงหน้าต่อไฟล์ สร้างบุ๊กมาร์ก
- **พิมพ์**: เลือกเครื่องพิมพ์ ช่วงหน้า จำนวนชุด ตัวอย่างก่อนพิมพ์ ปรับพอดีกระดาษ รองรับหน้าแนวนอน/แนวตั้งปนกัน

## รันจากซอร์ส (ทดสอบ)
```
py -3 -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
python main.py [ไฟล์.pdf ...]
```

## สร้างตัวติดตั้งแจกพนักงาน (Windows 10/11 64-bit)
1. ติดตั้ง Python 3.11 หรือ 3.12 (64-bit) จาก python.org (ติ๊ก *Add to PATH*)
2. ติดตั้ง [Inno Setup](https://jrsoftware.org/isinfo.php)
3. ดับเบิลคลิก `build_windows.bat` (หรือ `python build_release.py`) → ได้ `dist\PDF Governix\PDF Governix.exe` และ `installer\PDFGovernix_Setup.exe`
4. แจก `PDFGovernix_Setup.exe` ให้พนักงาน หรือติดตั้งผ่าน GPO/สคริปต์แบบเงียบ: `PDFGovernix_Setup.exe /VERYSILENT /TASKS="desktopicon"`

ปรับชื่อ/เวอร์ชัน/ชื่อบริษัท/ข้อความลิขสิทธิ์ได้ที่ `app/config.py` ที่เดียว

## ข้อควรรู้
- **แก้ข้อความเดิม**: ลบข้อความเดิมในกรอบแล้วเขียนใหม่ทับ (PDF ไม่มีโครงสร้างย่อหน้า จึงแก้ในที่เดิมแบบ Word ไม่ได้) — ฟอนต์ใหม่อาจต่างจากต้นฉบับเล็กน้อย
- เอกสารสแกน (เป็นภาพ) ไม่มีตัวอักษรให้เลือก: ใช้ “ลบ/ปิดทับ” + “ใส่ข้อความ” แทน (ยังไม่มี OCR)
- บันทึกไฟล์ที่เคยมีรหัสผ่านจะได้ไฟล์ไม่มีรหัสผ่าน (โปรแกรมแจ้งเตือนก่อน)
- ลายเซ็นที่นำเข้าเก็บไว้ที่ `%APPDATA%\Governix\PDFGovernix\signatures` ของแต่ละผู้ใช้
- รูป/ข้อความที่วางแล้วแก้ไขได้จนกว่าจะบันทึก — เมื่อบันทึกแล้วเปิดไฟล์ใหม่ จะกลายเป็นเนื้อหาในเอกสาร (แก้ได้ด้วยเครื่องมือ “แก้ข้อความ” หรือ “ลบ/ปิดทับ”)
- นี่คือลายเซ็นแบบภาพ ไม่ใช่ลายเซ็นดิจิทัลที่มีใบรับรอง (digital certificate)
- ทดสอบอัตโนมัติ (ไม่ต้องมีจอ): `python tests/test_ops.py`, `python tests/gui_smoke.py` และ `python tests/test_objects.py`

## โครงสร้าง
```
main.py              จุดเริ่มต้น
app/ops.py           คำสั่งกับ PDF (หน้า/รวม/มาร์กอัป/ลายน้ำ/แก้ข้อความ)

assets/fonts/        ฟอนต์ Prompt

app/viewer.py        ตัวแสดงผลเลื่อนต่อเนื่อง + เครื่องมือเมาส์
app/doctab.py        แท็บเอกสาร (ภาพย่อ + แก้ไข)    app/mainwindow.py  ริบบิ้น/แท็บ/แถบสถานะ
app/dialogs.py       รวมไฟล์/ใส่ข้อความ/แยกหน้า...   app/signatures.py  คลังลายเซ็น
app/printing.py      พิมพ์ + ตัวอย่างก่อนพิมพ์       app/theme.py       ธีม UI
```

## วิธีที่ง่ายที่สุด: ให้ GitHub สร้าง Setup.exe ให้ (ไม่ต้องลง Python)
1. สมัคร github.com (ฟรี) → New repository → ตั้งเป็น **Private**
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`) → Commit
3. แท็บ **Actions** → Build PDF Governix installer → **Run workflow** → รอ ~5-8 นาที
4. เปิดงานที่เสร็จแล้ว ดาวน์โหลด **PDFGovernix_Setup** (ไฟล์ zip ข้างในคือ `PDFGovernix_Setup.exe`) → แจกพนักงาน
