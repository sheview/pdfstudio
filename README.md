## ความสามารถ
- **ดูเอกสาร**: เลื่อนต่อเนื่อง ซูม (Ctrl+ลูกกลิ้ง) พอดีกว้าง/พอดีหน้า ภาพย่อ ค้นหา (Ctrl+F) คัดลอกข้อความ เปิดหลายไฟล์เป็นแท็บ ลากไฟล์มาวาง รองรับไฟล์มีรหัสผ่าน
- **รูป / ลายเซ็น / ข้อความ เป็นวัตถุอิสระ**: หลังวางแล้ว **คลิกเลือก → ลากย้าย → ลากมุมย่อขยาย** (รูป: มุม = คงสัดส่วน, กด Shift ที่มุม หรือลากขอบ = ยืดอิสระ • ข้อความ: ลากมุม = ย่อ/ขยายตัวอักษร, ลากขอบซ้าย/ขวา = ปรับความกว้าง) • ลูกศรบนคีย์บอร์ดขยับทีละ 1 pt (Shift = 10 pt) • **เลือกหลายชิ้น**: Ctrl/Shift+คลิกเพื่อเพิ่ม-เอาออก, Ctrl+ลากกรอบบนที่ว่าง (Shift = เพิ่มเข้ากลุ่ม), Ctrl+A เลือกทั้งหน้า → ย้าย/ลบ/ทำสำเนา/คัดลอก-วางพร้อมกัน คงตำแหน่งสัมพัทธ์ • **Ctrl+C / Ctrl+V** คัดลอก-วาง (ข้ามหน้า/ข้ามไฟล์ได้ วางภาพจากคลิปบอร์ดได้) • **Ctrl+D** ทำสำเนา • **Delete** ลบ • คลิกขวา: นำมาหน้าสุด/ส่งไปหลังสุด • ดับเบิลคลิกข้อความ (หรือ F2) เพื่อแก้ไข • ย้อนกลับ/ทำซ้ำได้ทุกขั้น — ตอนบันทึก/พิมพ์จึงฝังลงเอกสารจริง
- **ข้อความ**: ฟอนต์และขนาดเลือกจาก dropdown (หรือพิมพ์ขนาดเอง) ตัวหนา/เอียง/เส้นใต้ สี ชิดซ้าย-กลาง-ขวา แทรกวันที่ พ.ศ. — สระวรรณยุกต์ไทยถูกต้อง
- **แก้ / ลบ / เพิ่มข้อความบนเอกสารเดิม**: เครื่องมือ “แก้ข้อความ” คลิกที่ย่อหน้า (หรือลากกรอบเลือกบางส่วน) → แก้หรือกด “ลบข้อความนี้” — ข้อความที่แก้กลายเป็นกล่องข้อความ ย้าย/แก้ต่อได้ • เพิ่มข้อความใหม่ด้วย “ใส่ข้อความ”
- **ลายน้ำ**: ข้อความ (เช่น ลับ / ฉบับร่าง) หรือรูป/โลโก้ ปรับความโปร่งแสง มุมเอียง วางกลางหน้าหรือซ้ำเต็มหน้า อยู่หน้า/หลังเนื้อหา เลือกทุกหน้า/บางหน้า มีตัวอย่างก่อนใส่
- **มาร์กอัปอื่นๆ**: ไฮไลต์/ขีดเส้นใต้/ขีดฆ่า, วาดเส้น, ลบ/ปิดทับ, ปิดข้อมูลลับถาวร (Redact)
- **ตั้งรหัสผ่านเอกสาร** (แท็บหน้าแรก → ความปลอดภัย): เข้ารหัส AES-256 บันทึกเป็นไฟล์ใหม่ `_protected.pdf` — ทำกับเอกสารที่เปิดอยู่หรือเลือกหลายไฟล์พร้อมกัน จำกัดสิทธิ์ (ห้ามพิมพ์/คัดลอก/แก้ไข) ด้วยรหัสผู้ดูแลได้
- **จัดการหน้า**: หมุน ลบ แทรกหน้าว่าง ทำสำเนา เลื่อน/ลากสลับลำดับ แทรกจากไฟล์อื่น แยกหน้าเป็นไฟล์ใหม่ ส่งออกเป็นรูป
- **รวมไฟล์**: PDF + รูปภาพ หลายไฟล์ จัดลำดับ เลือกช่วงหน้าต่อไฟล์ สร้างบุ๊กมาร์ก
- **พิมพ์**: เลือกเครื่องพิมพ์ ช่วงหน้า จำนวนชุด ตัวอย่างก่อนพิมพ์ ปรับพอดีกระดาษ รองรับหน้าแนวนอน/แนวตั้งปนกัน

## สร้างตัวติดตั้งแจกพนักงาน (Windows 10/11 64-bit)
1. ติดตั้ง Python 3.11 หรือ 3.12 (64-bit) จาก python.org (ติ๊ก *Add to PATH*)
2. ติดตั้ง [Inno Setup](https://jrsoftware.org/isinfo.php)
3. ดับเบิลคลิก `build_windows.bat` (หรือ `python build_release.py`) → ได้ `dist\Governix PDF\Governix PDF.exe` และ `installer\GovernixPDF_Setup.exe`
4. แจก `GovernixPDF_Setup.exe` ให้พนักงาน หรือติดตั้งผ่าน GPO/สคริปต์แบบเงียบ: `GovernixPDF_Setup.exe /VERYSILENT /TASKS="desktopicon"`

ปรับชื่อ/เวอร์ชัน/ชื่อบริษัท/ข้อความลิขสิทธิ์ได้ที่ `app/config.py` ที่เดียว

## ข้อควรรู้
- **แก้ข้อความเดิม**: ลบข้อความเดิมในกรอบแล้วเขียนใหม่ทับ (PDF ไม่มีโครงสร้างย่อหน้า จึงแก้ในที่เดิมแบบ Word ไม่ได้) — ฟอนต์ใหม่อาจต่างจากต้นฉบับเล็กน้อย
- เอกสารสแกน (เป็นภาพ) ไม่มีตัวอักษรให้เลือก: ใช้ “ลบ/ปิดทับ” + “ใส่ข้อความ” แทน (ยังไม่มี OCR)
- บันทึกไฟล์ที่เคยมีรหัสผ่านจะได้ไฟล์ไม่มีรหัสผ่าน (โปรแกรมแจ้งเตือนก่อน)
- ลายเซ็นที่นำเข้าเก็บไว้ที่ `%APPDATA%\Governix\PDFGovernix\signatures` ของแต่ละผู้ใช้
- รูป/ข้อความที่วางแล้วแก้ไขได้จนกว่าจะบันทึก — เมื่อบันทึกแล้วเปิดไฟล์ใหม่ จะกลายเป็นเนื้อหาในเอกสาร (แก้ได้ด้วยเครื่องมือ “แก้ข้อความ” หรือ “ลบ/ปิดทับ”)
- นี่คือลายเซ็นแบบภาพ ไม่ใช่ลายเซ็นดิจิทัลที่มีใบรับรอง (digital certificate)
- ทดสอบอัตโนมัติ (ไม่ต้องมีจอ): `python tests/test_ops.py`, `python tests/gui_smoke.py` และ `python tests/test_objects.py` และ `python tests/test_protect.py`

## วิธีที่ง่ายที่สุด: ให้ GitHub สร้าง Setup.exe ให้ (ไม่ต้องลง Python)
1. สมัคร github.com (ฟรี) → New repository → ตั้งเป็น **Private**
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`) → Commit
3. แท็บ **Actions** → Build Governix PDF installer → **Run workflow** → รอ ~5-8 นาที
4. เปิดงานที่เสร็จแล้ว ดาวน์โหลด **GovernixPDF_Setup** (ไฟล์ zip ข้างในคือ `GovernixPDF_Setup.exe`) → แจกพนักงาน

## อัปเดตรอบที่ 2 (จากการทดลองใช้จริง)
- **พิมพ์**: ปรับวิธีส่งงานพิมพ์ใหม่ (ความละเอียด 200 dpi, ไม่สลับแนวกระดาษกลางงาน, ยกเลิกได้ระหว่างพิมพ์) และมีปุ่มสำรอง **พิมพ์ผ่านระบบ** (แท็บหน้าแรก → พิมพ์) เปิดไฟล์ในโปรแกรมอ่าน PDF ของเครื่องเพื่อสั่งพิมพ์จากที่นั่น
- **ลากสลับ/ย้ายหน้า**: ลากภาพย่อด้านซ้ายไปวางที่ใหม่ได้เลย (เลือกหลายหน้าแล้วลากทีเดียวได้ มีเส้นม่วงบอกตำแหน่งที่จะวาง) — รูป/ข้อความที่วางไว้ตามหน้าไปด้วยและยังแก้ไขได้ (ทำเหมือนกันกับ ลบ/แทรก/ทำสำเนาหน้า) มีเพียง "หมุนหน้า", "ลบข้อความ/ปิดข้อมูลลับ" ที่จะฝังรูปลงเอกสารก่อน
- **บันทึกแล้วยังแก้รูป/ข้อความต่อได้**: ไฟล์ PDF ที่บันทึกจาก Governix PDF จะแนบข้อมูลชั้นรูป/ข้อความไว้ในไฟล์ (ไฟล์แนบชื่อ `governix-editable.zip`, ไฟล์จะใหญ่ขึ้นประมาณเท่าตัวเมื่อมีรูป/ข้อความลอย) — เปิดด้วย Governix PDF ครั้งหน้าจะกลับมาย้าย/ย่อขยายได้ ถ้าไฟล์ถูกแก้ด้วยโปรแกรมอื่นหลังจากนั้นจะไม่กู้คืน (เปิดเป็นเอกสารปกติ)
- **รูปซ้อนกัน**: กด **Alt + คลิก** เพื่อเลือกรูปที่อยู่ใต้ชิ้นบน; คลิกถี่ ๆ/ดับเบิลคลิกที่รูปแล้วลากต่อได้
- **ครอปรูป / ลบพื้นหลัง** (แท็บแก้ไข → วัตถุที่เลือก หรือคลิกขวาที่รูป): ครอปแบบลากกรอบ ล็อกสัดส่วนได้ • ลบพื้นหลังทำในเครื่อง (ไม่ใช้อินเทอร์เน็ต) ปรับความไว/ความนุ่มขอบ คลิกบนรูปเพื่อเลือกสีที่จะลบ — เหมาะกับลายเซ็น โลโก้ ตราประทับ และรูปพื้นเรียบ (รูปถ่ายที่พื้นหลังซับซ้อนยังทำได้ไม่ดี)
- **บันทึกเป็น .pdf / .docx / .jpg**: ปุ่ม "บันทึกเป็น" เลือกชนิดไฟล์ได้ — Word มี 2 แบบ (แก้ข้อความได้ผ่าน pdf2docx / เหมือนต้นฉบับเป็นรูปทั้งหน้า), JPEG เลือกหน้า ความละเอียด และคุณภาพได้ (หลายหน้า = หลายไฟล์)

## Serial Number (ถามตอนติดตั้งเท่านั้น)
- ตัวติดตั้งจะมีหน้า "Serial Number" ต้องกรอกให้ถูกจึงติดตั้งต่อได้ — เปิดโปรแกรมหลังติดตั้งแล้วไม่ถามอีก
- ติดตั้งแบบเงียบ (IT แจกหลายเครื่อง): `GovernixPDF_Setup.exe /VERYSILENT /SERIAL=xxxx-xxxxxxxxxx`
- ในไฟล์ติดตั้งเก็บเฉพาะค่าแฮช (ดูส่วน `[Code]` ใน `installer.iss` วิธีเปลี่ยน Serial อยู่ในคอมเมนต์)
- หมายเหตุ: ใครมีตัวติดตั้ง + Serial ก็ติดตั้งได้ทุกเครื่อง และโฟลเดอร์โปรแกรมที่ติดตั้งแล้วถูกคัดลอกไปรันที่อื่นได้ — กันได้เฉพาะคนทั่วไปที่ไม่มี Serial

## โหมดนำเสนอ (เต็มจอ)
- แท็บหน้าแรก → กลุ่ม **นำเสนอ**: `F5` เริ่มจากหน้าแรก, `Shift+F5` เริ่มจากหน้าที่กำลังดู, **ตั้งค่านำเสนอ** เลือกเอฟเฟกต์ (เฟด / สไลด์ / เลื่อนขึ้น / ไม่มี) ความเร็ว เปลี่ยนหน้าอัตโนมัติทุกกี่วินาที และวนกลับหน้าแรก
- ตอนนำเสนอ: `→ ↓ Space คลิก` หน้าถัดไป • `← ↑ Backspace คลิกขวา` ย้อนกลับ • `Home/End` • พิมพ์เลขหน้า + `Enter` ไปหน้านั้น • `B` จอดำ • `W` จอขาว • `L` เลเซอร์พอยน์เตอร์ • `Esc` ออก
- รูป/ข้อความ/QR ที่วางไว้แสดงด้วย, เมาส์ซ่อนเองเมื่อไม่ขยับ, กันจอดับระหว่างนำเสนอ (Windows)


### โหมดนำเสนอ: ปากกา / ซูม / เลือกจอ
- `D` ปากกา, `H` ไฮไลต์ (ลากเมาส์วาด คลิกไม่เปลี่ยนหน้า), `C` เปลี่ยนสี, `U` ลบเส้นล่าสุด, `E` ลบเส้นทั้งหน้า (เส้นอยู่เฉพาะตอนนำเสนอ ไม่ถูกบันทึกลง PDF)
- `Z` ซูมเข้า/ออก, `Ctrl+ล้อเมาส์` หรือ `+`/`-` ปรับซูม, `F` รีเซ็ต; ตอนซูมให้ปิดปากกาแล้วลากเมาส์เพื่อเลื่อนดู; เปลี่ยนหน้าแล้วซูมรีเซ็ต
- ตั้งค่านำเสนอ → "แสดงนำเสนอบนจอ" เลือกจอโปรเจกเตอร์ได้
